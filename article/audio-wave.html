物理太玄了，先理解對聲音設計有幫助的部份

  • 一部分的標準值是為了溝通被定義的
  • 人類能感知到的聲音、可以觀測到的聲音不同
  • 聽覺敏感是對於空氣的密度變化敏感
  • 震動是有效改變空氣密度的方法
  • 聲音很相似指的是範圍(時間、空間)內的空氣密度變化很相似

頻率

  • 音高 A4 是 1 秒內相同空氣密度變化重複約 432 ~ 443 次 (Hz)
  • 220 次為 A3 、 880 次為音高 A5 …
  • 絕對音感可以理解成，能感知出 1 秒內相同變化重複了幾次

震幅

  • 某個區域內空氣分子數量越多(密度變化大)聽覺感知到的音量也就大
  • 常見的測量單位 db 是為了人類聽覺感知定義的

波長

  • 聲音速度(固定常數) = 頻率 * 波長(距離) => 低頻率波長 > 高頻率波長
  • 若不考慮能量衰減，平面位置[0,1,2,3,4,5,6,7,8] 位置 [0, 4, 6] 感受到的低頻能力(震幅) > [1, 5, 7]
  • 所以「距離越遠聲音越小」不一定成立，如果觀察單位超小是 xx 、 yy 與 zz 感受到的震幅可能會是 xx > zz > yy

相位

  • 週期始於振福 0 的位置，習慣用度數表示時間狀態
  • 振幅的現象可以用加法計算，通相位相反震幅的能量相加會得到振福 0
  • 要記得聽覺是由耳朵鼓膜傳遞，振福 0 代表的是鼓膜不動作，不太表物理上的作用
  • 很多酷酷的聲音都是相位後的結果，也不好複製

包絡

  • 描述聲音的變化過程，分為起音（attack）、衰減（decay）、持續（sustain）和釋音（release）
  • 代表聲波能量外廓的真實物理變化(溝通用非定義)，時間顆粒度通常使用毫秒

頻譜

  • 描述聲音的頻率成分，通常分成基音（Fundamental frequency）、泛音（Overtones）
  • 基音是最底層週期性頻率，影響聽覺感受到的音高
  • 泛音基於是否為基音的倍數，可以再被分為諧波、非諧波
  • 這些震幅與包絡混在一起就形成音色

空間

  • 頭部會擋住高頻聲音，使遠側耳朵聽到的聲音較小、較悶
  • 聲音到達左右耳的微小時間先後，讓大腦判斷水平左右方向
  • 聽音辨位就是綜合時間差 + 能量差 + 反射音

心理

  • 人耳 20 ~ 50hz 不敏感、2khz ~ 4khz 敏感
  • 敏感的標準是相同 db 的感受度，且音量越低感受度差異越大
  • 可以用來解釋為什麼大聲的音樂比較好聽，實用小技巧是可以做非線性高、低頻增益
